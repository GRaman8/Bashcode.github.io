Section 4: Vim Editor Guide

Vim is a highly configurable, terminal-based text editor. It operates in different modes — understanding modes is the key to using Vim effectively.

Vim Modes at a Glance:
Normal Default mode — navigate, copy, delete, run commands.
Insert Type and edit text like a regular editor.
Visual Select text for copying, deleting, or replacing.
Command Run ex-commands like save, quit, search/replace.

Opening & Closing Vim

vim filename
Usage: Open a file in Vim
Description: If the file does not exist, Vim creates it when you save.
vim
Usage: Open Vim without a file (scratch buffer)
vim +N filename
Usage: Open file and jump to line N
Description: e.g., vim +42 app.py opens app.py at line 42.
vim -R filename
Usage: Open file in read-only mode
Other Ways: view filename
:q Command
Usage: Quit Vim (only works if no unsaved changes)
:q! Command
Usage: Force quit without saving
:w Command
Usage: Save (write) the current file
:wq Command
Usage: Save and quit
Other Ways: :x  |  ZZ (Normal mode)
:w filename Command
Usage: Save as a new filename (keeps original open)
:saveas filename Command
Usage: Save as and switch to new filename

Switching Modes

i Normal
Usage: Enter Insert mode before the cursor
I Normal
Usage: Enter Insert mode at the beginning of the line
a Normal
Usage: Enter Insert mode after the cursor
A Normal
Usage: Enter Insert mode at the end of the line
o Normal
Usage: Open a new line below and enter Insert mode
O Normal
Usage: Open a new line above and enter Insert mode
s Normal
Usage: Delete character under cursor and enter Insert mode
S Normal
Usage: Delete entire line and enter Insert mode
v Normal
Usage: Enter Visual (character) mode
V Normal
Usage: Enter Visual Line mode (select whole lines)
Ctrl+v Normal
Usage: Enter Visual Block mode (column/rectangle select)
: Normal
Usage: Enter Command-line mode
Esc Insert Visual
Usage: Return to Normal mode from any other mode
Other Ways: Ctrl+[ (same as Esc)

Navigation (Normal Mode)

h   j   k   l Normal
Usage: Move left / down / up / right
Description: Arrow keys work too, but hjkl keeps your hands on the home row.
w Normal
Usage: Jump to start of next word
Other Ways: W (jump by whitespace-delimited word)
b Normal
Usage: Jump to start of previous word
Other Ways: B (whitespace-delimited)
e Normal
Usage: Jump to end of current/next word
0 Normal
Usage: Jump to beginning of the line
^ Normal
Usage: Jump to first non-whitespace character of the line
$ Normal
Usage: Jump to end of the line
gg Normal
Usage: Jump to first line of the file
G Normal
Usage: Jump to last line of the file
:N Command
Usage: Jump to line number N
Description: e.g., :50 jumps to line 50. Also Ngg or NG in Normal mode.
Ctrl+f Normal
Usage: Scroll one page forward (down)
Other Ways: Page Down
Ctrl+b Normal
Usage: Scroll one page backward (up)
Other Ways: Page Up
Ctrl+d Normal
Usage: Scroll half-page down
Ctrl+u Normal
Usage: Scroll half-page up
{   } Normal
Usage: Jump to previous / next empty line (paragraph)
% Normal
Usage: Jump to matching bracket — ( ), [ ], { }
fx Normal
Usage: Jump to next occurrence of character x on the current line
Other Ways: Fx (jump backward), tx (just before x), Tx

Editing — Delete, Copy, Paste

x Normal
Usage: Delete character under cursor
Other Ways: X (delete character before cursor)
dd Normal
Usage: Delete (cut) the current line
Description: Ndd deletes N lines (e.g., 3dd deletes 3 lines).
dw Normal
Usage: Delete from cursor to end of word
Other Ways: dW, d$ (to end of line), d0 (to start of line), dG (to end of file)
D Normal
Usage: Delete from cursor to end of line
yy Normal
Usage: Yank (copy) the current line
Description: Nyy copies N lines (e.g., 5yy copies 5 lines).
Other Ways: Y (same as yy)
yw Normal
Usage: Yank from cursor to end of word
Other Ways: y$ (to end of line), yG (to end of file)
p Normal
Usage: Paste after cursor / below current line
Other Ways: P (paste before cursor / above current line)
r Normal
Usage: Replace single character under cursor (stay in Normal mode)
R Normal
Usage: Enter Replace mode — overwrite characters as you type
cc Normal
Usage: Delete line and enter Insert mode (change line)
Other Ways: cw (change word), c$ (change to end of line), C (same as c$)
~ Normal
Usage: Toggle case of character under cursor
J Normal
Usage: Join current line with the line below
>> Normal
Usage: Indent current line one level to the right
Other Ways: << (un-indent)

Undo & Redo

u Normal
Usage: Undo last change
Description: Press repeatedly to undo multiple changes.
Ctrl+r Normal
Usage: Redo (undo the undo)
U Normal
Usage: Undo all changes on the current line
. Normal
Usage: Repeat the last change
Description: One of the most powerful Vim shortcuts — repeat any edit without retyping it.

Search & Replace

/pattern Normal
Usage: Search forward for pattern
Description: Press Enter to confirm. n jumps to next match, N to previous.
?pattern Normal
Usage: Search backward for pattern
n Normal
Usage: Jump to next search match
Other Ways: N (previous match)
* Normal
Usage: Search forward for the word under cursor
Other Ways: # (search backward for word under cursor)
:s/old/new/ Command
Usage: Replace first occurrence of "old" with "new" on the current line
:s/old/new/g Command
Usage: Replace all occurrences of "old" with "new" on the current line
:%s/old/new/g Command
Usage: Replace all occurrences in the entire file
:%s/old/new/gc Command
Usage: Replace all occurrences in the file with confirmation prompt
Description: After each match, press y (yes), n (no), a (all), q (quit), l (last).
:noh Command
Usage: Clear search highlight
Other Ways: :nohlsearch

Visual Mode — Selecting Text

v then motion Visual
Usage: Select text character by character using movement keys
Description: e.g., v then w selects to end of next word.
V Normal
Usage: Select entire lines
d Visual
Usage: Delete selected text
y Visual
Usage: Yank (copy) selected text
> Visual
Usage: Indent selected lines
Other Ways: < (un-indent)
~ Visual
Usage: Toggle case of selected text
Other Ways: u (lowercase), U (uppercase)

Multiple Files & Split Windows

:e filename Command
Usage: Open another file in the current window
:sp filename Command
Usage: Open file in a horizontal split
Other Ways: :split filename
:vsp filename Command
Usage: Open file in a vertical split
Other Ways: :vsplit filename
Ctrl+w then h/j/k/l Normal
Usage: Move focus between split windows
Description: Arrow keys also work after Ctrl+w.
Ctrl+w then q Normal
Usage: Close the current split window
:tabnew filename Command
Usage: Open file in a new tab
gt Normal
Usage: Go to next tab
Other Ways: gT (previous tab)
:ls Command
Usage: List all open buffers
:bn Command
Usage: Go to next buffer
Other Ways: :bp (previous buffer), :b N (buffer by number)

Marks & Jump List

mx Normal
Usage: Set mark x at current position (x = any letter a–z)
`x Normal
Usage: Jump to exact position of mark x
Other Ways: 'x (jump to start of line with mark x)
Ctrl+o Normal
Usage: Jump to previous location in jump list
Other Ways: Ctrl+i (jump forward in jump list)

Macros — Record & Replay

qx Normal
Usage: Start recording macro into register x (x = any letter)
q Normal
Usage: Stop recording macro
@x Normal
Usage: Replay macro stored in register x
Description: N@x replays the macro N times. @@ replays the last used macro.

Useful Settings (Command Mode)

:set number Command
Usage: Show line numbers
Other Ways: :set nu | :set nonumber to hide
:set relativenumber Command
Usage: Show relative line numbers (great for jumping N lines)
:set hlsearch Command
Usage: Highlight all search matches
:set ignorecase Command
Usage: Make search case-insensitive
Other Ways: :set smartcase (case-insensitive unless uppercase used in search)
:set tabstop=4 Command
Usage: Set tab width to 4 spaces
:set expandtab Command
Usage: Convert tabs to spaces
:set autoindent Command
Usage: Auto-indent new lines to match the previous line
:syntax on Command
Usage: Enable syntax highlighting
:colorscheme NAME Command
Usage: Change color scheme (e.g., :colorscheme desert)

Miscellaneous

:! command Command
Usage: Run a shell command without leaving Vim
Description: e.g., :! ls or :! python3 script.py
:r filename Command
Usage: Insert contents of a file below the cursor
:r ! command Command
Usage: Insert output of a shell command into the buffer
Description: e.g., :r ! date inserts the current date.
Ctrl+g Normal
Usage: Show current file name, line number, and percentage through file
ga Normal
Usage: Show ASCII / Unicode value of character under cursor
:help topic Command
Usage: Open Vim's built-in help for a topic
Description: e.g., :help dd or :help motion. Press Ctrl+] on a tag to jump into it.
:set paste Command
Usage: Disable auto-indent while pasting from system clipboard
Other Ways: :set nopaste to re-enable

Common Use-Cases & Workflows

Quick config file edit
Description: vim ~/.bashrc — open, make changes, :wq to save and exit.
Rename a variable across a file
Description: :%s/oldName/newName/gc — replace with confirmation on every match.
Delete all blank lines in a file
Description: :g/^$/d — the global command matches all empty lines and deletes them.
Comment out a block of lines
Description: Use Ctrl+v to enter Visual Block, select lines, press I, type #, then Esc.
Repeat an edit on many lines
Description: Make the edit on one line, then press j. (dot) to move down and repeat.
View two files side by side
Description: vim -O file1 file2 opens both in a vertical split. Use Ctrl+w+l/h to switch.
Compare two files (vimdiff)
Description: vimdiff file1 file2 — highlights differences between files. ]c / [c jump between diffs.
