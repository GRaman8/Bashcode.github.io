Section 2: Conda Commands Guide

Conda is a powerful package and environment management tool commonly used in data science, machine learning, and scientific computing. It handles dependencies, versions, and isolates project environments.

Conda Basics:
• Create separate environments for different projects
• Install packages with version control
• Conda is language-agnostic (Python, R, C++, etc.)
• Use mamba for faster package solving (drop-in Conda replacement)

Environment Management

conda create --name myenv
Usage: Create a new environment
conda create --name data-science python=3.10
Description: Create named environment. Optionally specify Python version.
conda activate myenv
Usage: Activate an environment
conda activate data-science
Description: Switches to the specified environment. Notice prompt changes to show active environment.
conda deactivate
Usage: Deactivate current environment (return to base)
conda deactivate
conda env list
Usage: List all environments
conda env list
Other Ways: conda info --envs
conda remove --name myenv --all
Usage: Remove an environment and all packages
conda remove --name old-project --all

Package Management

conda install package_name
Usage: Install a package in the current environment
conda install numpy pandas matplotlib
Description: Can install multiple packages at once. Install only in active environment.
conda install -n env_name package_name
Usage: Install package in a specific environment
conda install -n data-science scikit-learn
Description: -n flag specifies target environment without activating it.
conda install package_name=version
Usage: Install specific version of a package
conda install numpy=1.21.0
Description: Version pinning prevents unwanted updates.
conda list
Usage: List all installed packages in current environment
conda list
Other Ways: conda list -n env_name (list packages in specific env)
conda search package_name
Usage: Search for available packages
conda search tensorflow
Description: Shows all available versions in configured channels.
conda update package_name
Usage: Update a package to latest version
conda update numpy
conda remove package_name
Usage: Remove a package
conda remove jupyter

Maintenance & Configuration

conda update conda
Usage: Update Conda itself
conda update conda
conda update anaconda
Usage: Update all Anaconda packages
conda update anaconda
conda clean --all
Usage: Remove unused packages and caches
conda clean --all
Description: Frees up disk space by removing cached installers and unused packages.
conda info
Usage: Display Conda configuration and system info
conda info

Environment Files & Sharing

conda env export > environment.yml
Usage: Export environment to a file
conda env export > environment.yml
Description: Creates a YAML file with all packages and versions for sharing/reproduction.
conda env create -f environment.yml
Usage: Create environment from file
conda env create -f environment.yml
Description: Recreate environment with exact packages/versions from exported file.

Channels & Package Sources

conda config --add channels conda-forge
Usage: Add a package channel
conda config --add channels conda-forge
Description: Expand available packages. conda-forge has many community packages.
conda config --show channels
Usage: View configured channels
conda config --show channels
Pro Tips:
• Use mamba for faster installation (install with: conda install -c conda-forge mamba)
• Always create new environments for new projects
• Use environment.yml for team collaboration
• Clean cache regularly with conda clean --all
