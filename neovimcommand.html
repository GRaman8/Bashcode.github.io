Section 6: Neovim & NvChad — Modern Terminal Text Editing

Neovim is a modern fork of Vim with better extensibility, async support, and a Lua-based configuration. NvChad is a feature-rich Neovim config distribution that comes pre-configured with beautiful UI, plugins, and sensible defaults — making Neovim user-friendly out of the box.

What's the difference?
Vim: Classic, stable, traditional configuration (vimscript).
Neovim: Modern fork of Vim with Lua scripting, async/await, better plugin architecture, terminal support.
NvChad: Pre-configured Neovim distribution with themes, plugins, keybindings, and LazyVim-style plugin management built-in.

Installation & Setup

Linux/macOS: Install Neovim
# Ubuntu/Debian sudo apt install neovim # macOS (Homebrew) brew install neovim # Using AppImage (any Linux) wget https://github.com/neovim/neovim/releases/download/stable/nvim.appimage chmod +x nvim.appimage sudo mv nvim.appimage /usr/local/bin/nvim
Install NvChad (Quick Setup)
git clone https://github.com/NvChad/NvChad ~/.config/nvim --depth 1 nvim # NvChad will auto-install plugins on first launch
Description: NvChad replaces your default Neovim config. Your custom configs go in ~/.config/nvim/lua/custom/.
Verify Installation
nvim --version

Basic Usage (Same as Vim)

nvim filename
Usage: Open file in Neovim
nvim app.py
nvim +N filename
Usage: Open file and jump to line N
nvim +42 app.py
nvim
Usage: Open Neovim with empty buffer
All Vim commands work in Neovim!
Since Neovim is based on Vim, all standard Vim commands (hjkl navigation, dd, yy, :wq, /pattern, etc.) work identically. Refer to the Vim guide for these fundamentals.

NvChad — Key Features & Plugins

Telescope NvChad
Description: Powerful fuzzy finder for files, buffers, and live grep. Use <space>ff, <space>fw, <space>fb.
NvimTree NvChad
Description: File explorer sidebar. Toggle with <C-n> or <space>e. Navigate with arrow keys, 'a' to create, 'd' to delete, 'r' to rename.
Treesitter NvChad
Description: Advanced syntax highlighting and code understanding. Better than regex-based highlighting.
Language Server Protocol (LSP) NvChad
Description: Code intelligence — go to definition, rename, documentation, diagnostics. Supports 50+ languages.
Mason NvChad
Description: LSP/tool package manager. Install language servers, formatters, linters easily. Use <space>ma.
null-ls NvChad
Description: Bridges external formatters and linters to NvChad (Prettier, Black, ESLint, etc.).
nvim-cmp NvChad
Description: Autocomplete engine with support for LSP, snippets, path completion, and more.
Leap NvChad
Description: Fast, precise cursor motion. Better than f/F searching. Press 's' to activate, then type 2 chars to jump.
Gitsigns NvChad
Description: Show Git status in the left gutter — added/modified/deleted lines at a glance.

Configuration Basics

Config location
~/.config/nvim/init.lua (Neovim with Lua)
Description: Main config file. For NvChad, customize in ~/.config/nvim/lua/custom/
Check configuration location
nvim --version | grep "Vimrc\\|Config"
OR open Neovim and type: :echo $MYVIMRC
Reload configuration
:source ~/.config/nvim/init.lua
OR in Neovim: :luafile %
NvChad custom config directory
~/.config/nvim/lua/custom/
Description: All custom settings go here. NvChad loads files from this directory.
Set options (Lua)
-- In init.lua or custom config vim.opt.number = true -- Show line numbers vim.opt.relativenumber = true -- Relative line numbers vim.opt.tabstop = 4 -- Tab width vim.opt.expandtab = true -- Use spaces instead of tabs vim.opt.autoindent = true -- Auto-indent vim.opt.ignorecase = true -- Case-insensitive search
Custom keybindings (Lua)
local map = vim.keymap.set map('n', '<space>w', ':write<CR>', { noremap = true }) map('i', '<C-s>', '<Esc>:write<CR>', { noremap = true })
Install plugins (using lazy.nvim)
-- In ~/.config/nvim/lua/custom/plugins.lua return { { "plugin-author/plugin-name", config = function() require("plugin-name").setup({}) end } }
Description: NvChad uses lazy.nvim for plugin management. Plugins auto-install on startup.

Vim vs Neovim vs NvChad

Feature Vim Neovim NvChad
Learning Curve Moderate Same as Vim Easy (pre-configured)
Out-of-box Experience Minimal config needed Requires custom config Beautiful UI, ready to use
Configuration Language Vimscript Vimscript or Lua Lua (modern)
Plugin Management Manual or plugin manager Plugin manager (vim-plug, etc.) lazy.nvim (built-in)
LSP Support Via plugin (coc.nvim) Native LSP client Native LSP + pre-configured
Async Support Limited Full async/await Full async/await
Terminal Integration No Yes (:terminal) Yes (:terminal)
Treesitter No Via plugin Pre-configured
File Explorer netrw (basic) Via plugin NvimTree (beautiful)
Fuzzy Finder Via plugin Via plugin (Telescope) Telescope (pre-configured)
Setup Time Minutes Hours (if starting from scratch) Seconds (just clone)
Customization Limited Highly customizable Customizable (but started with defaults)

NvChad Directory Structure

After installing NvChad:
~/.config/nvim/
├── init.lua — Main entry point (don't edit)
├── lua/ — Lua configuration
│ ├── core/ — NvChad core (don't edit)
│ ├── plugins/ — Pre-installed plugins
│ └── custom/ — Your customizations
│ ├── chadrc.lua — Customize UI, theme, disabled features
│ ├── init.lua — Add your settings here
│ └── plugins.lua — Add your plugins here

Customization Examples

Change theme
-- In ~/.config/nvim/lua/custom/chadrc.lua local M = {} M.ui = { theme = "onedark", -- other options: gruvbox, monokai, nord, etc. } return M
Disable features
-- In ~/.config/nvim/lua/custom/chadrc.lua M.ui = { tabufline = { enabled = false }, -- Hide tab bar nvdash = { enabled = false }, -- Hide dashboard }
Add custom plugins
-- In ~/.config/nvim/lua/custom/plugins.lua return { { "numToStr/Comment.nvim", -- Comment plugin config = function() require("Comment").setup() end }, { "folke/todo-comments.nvim", -- Highlight TODO/FIXME } }

Common Workflows & Use-Cases

Quick project setup
cd ~/my-project nvim # Opens NvChad dashboard <space>ff # Find files, start coding
Refactor code with LSP
1. Position cursor on function/variable name 2. <space>rn (rename symbol) 3. Type new name 4. All references updated automatically
View function signature while coding
K # Shows type, params, docstring for symbol under cursor
Run code in terminal split
:split | terminal i (enter terminal mode) python app.py <C-\><C-n> (exit terminal mode)
Format entire file on save
-- In ~/.config/nvim/lua/custom/init.lua vim.api.nvim_create_autocmd("BufWritePre", { callback = function() vim.cmd("silent! lua vim.lsp.buf.format()") end })
Search and replace across project
<space>fw # Find word Select results with <C-q> <space>ra # Code action (if available)

Tips & Tricks

Speed up cursor movement with Leap
s + 2 chars = jump to that location (NvChad has Leap pre-installed) Much faster than f/F or /search
Browse file tree efficiently

-- In ~/.config/nvim/lua/custom/chadrc.lua M.ui.nvdash = { enabled = false }

Debugging & Troubleshooting

LSP not working?
1. <space>ma — Open Mason, install language server for your language 2. :LspInfo — Check if LSP is attached to current buffer 3. :Mason — Manage installed servers
Formatter not working?
1. <space>ma — Install formatter (e.g., Prettier, Black) 2. Check null-ls config: ~/.config/nvim/lua/custom/configs/null-ls.lua 3. :NullLsInfo — Debug null-ls status
Check configuration errors
:checkhealth
Description: Comprehensive health check. Shows missing dependencies, plugin issues, etc.
Reload configuration without restarting
:luafile %
:source ~/.config/nvim/init.lua
