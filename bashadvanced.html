Advanced Shell Mastery — Full Stack & Cloud Engineering

Advanced shell techniques, I/O redirection, process management, and workflows for Full Stack Developers and Cloud Engineers. These commands work in both Bash and Zsh.

Perfect For:
• Local development (Zsh) and cloud servers (Bash)
• Docker, AWS, and DevOps workflows
• Node.js, Python, Go development
• Log analysis and performance monitoring
• Git and deployment automation

I/O Redirection & Piping

Output Redirection

command > file
Usage: Redirect output to file (overwrite)
echo "Hello World" > output.txt
command >> file
Usage: Append output to file
echo "New line" >> output.txt
command 2> file
Usage: Redirect errors (stderr) to file
npm install 2> errors.log
Description: Useful for capturing error logs separately.
command 2>> file
Usage: Append errors to file
docker build . 2>> build-errors.log
command &> file
Usage: Redirect both stdout and stderr to same file
python script.py &> output.txt
command 1> out.txt 2> err.txt
Usage: Redirect stdout and stderr to different files
npm test 1> test-output.txt 2> test-errors.txt
command > /dev/null 2>&1
Usage: Discard all output (suppress errors)
docker ps > /dev/null 2>&1 && echo "Docker running"
Description: Useful for silent execution or checking exit status only.

Input Redirection

command < file
Usage: Redirect file as input to command
grep "error" < server.log
command1 | command2
Usage: Pipe (send output of command1 to command2)
docker ps | grep "redis"
command1 | command2 | command3
Usage: Chain multiple pipes
cat package.json | grep "dependencies" | head -5
command << 'EOF' ... EOF
Usage: Here-document (multi-line input)
cat > script.sh << 'EOF' #!/bin/bash echo "Hello" EOF
Description: Useful for creating files or scripts inline.
command <<< "string"
Usage: Here-string (pass string as input)
wc -w <<< "Hello World"

Advanced Piping

command1 |& command2
Usage: Pipe both stdout and stderr
npm install |& tee install.log
Description: Captures all output including errors.
tee
Usage: Save output to file AND display on terminal
docker build . | tee build.log
Description: Useful for logging while watching output.
tee -a file
Usage: Append to file while displaying
npm test | tee -a test-results.txt

Process Management & Job Control

command &
Usage: Run command in background
npm start &
Description: Process runs in background, returns to prompt.
Ctrl+Z
Usage: Suspend running process
Description: Pause current process, returns to prompt.
bg
Usage: Resume suspended process in background
bg %1
fg
Usage: Bring background process to foreground
fg %1
jobs
Usage: List all background jobs
jobs
Other Ways: jobs -l (with PIDs), jobs -p (only PIDs)
ps aux | grep process
Usage: List running processes matching pattern
ps aux | grep "node"
ps aux
Usage: List all running processes
ps aux
Description: a=all users, u=detailed, x=background processes.
kill PID
Usage: Terminate process by PID
kill 1234
kill -9 PID
Usage: Force kill process (SIGKILL)
kill -9 1234
⚠️ Force kill doesn't allow cleanup. Use as last resort.
killall process_name
Usage: Kill all processes by name
killall node
nohup command &
Usage: Run command immune to hangups (survives logout)
nohup npm start > app.log 2>&1 &
Description: Perfect for running long processes on remote servers.
disown %1
Usage: Remove job from shell tracking
disown %1
Description: Process continues even if terminal closes.

Process Substitution & Advanced Patterns

diff <(command1) <(command2)
Usage: Compare outputs of two commands
diff <(docker images | sort) <(docker images | head -5)
Description: Powerful for comparing command outputs without temp files.
command1 && command2
Usage: Run command2 only if command1 succeeds
cd project && npm install && npm start
command1 || command2
Usage: Run command2 only if command1 fails
docker ps || echo "Docker not running"
command1; command2; command3
Usage: Run commands sequentially (regardless of success)
git add . ; git commit -m "fix" ; git push

Text Processing for Log Analysis

grep "pattern" file.txt
Usage: Search for text pattern in file
grep "ERROR" app.log
grep -i "pattern" file.txt
Usage: Case-insensitive grep
grep -i "error" app.log
grep -r "pattern" /path/
Usage: Recursive grep (search in all files)
grep -r "TODO" src/
grep "pattern" file | wc -l
Usage: Count matching lines
grep "ERROR" server.log | wc -l
tail -f file.log
Usage: Follow log file (watch new lines in real-time)
tail -f /var/log/docker.log
Description: Great for monitoring logs. Press Ctrl+C to stop.
tail -n 20 file.log
Usage: Show last 20 lines
tail -n 50 docker.log
head -n 10 file.log
Usage: Show first 10 lines
head -n 20 build.log
sed 's/old/new/g' file.txt
Usage: Find and replace (sed substitute)
sed 's/localhost/127.0.0.1/g' config.txt
sed -i 's/old/new/g' file.txt
Usage: In-place find and replace
sed -i 's/DEBUG/INFO/g' app.log
⚠️ Modifies original file. Backup first!
awk '{print $1, $3}' file.txt
Usage: Extract specific columns
ps aux | awk '{print $2, $11}' (PID and command)
Description: $1=column1, $2=column2, etc. Space-delimited.
cut -d',' -f1,3 file.csv
Usage: Extract columns by delimiter
cut -d',' -f1,2 data.csv
Description: -d=delimiter, -f=field numbers.
sort file.txt
Usage: Sort lines
sort servers.txt
sort -u file.txt
Usage: Sort and remove duplicates
ps aux | awk '{print $1}' | sort -u
uniq file.txt
Usage: Remove consecutive duplicate lines
sort file.txt | uniq
tr 'a-z' 'A-Z' < file.txt
Usage: Translate characters (e.g., lowercase to uppercase)
echo "hello" | tr 'a-z' 'A-Z'

Performance Monitoring & System Info

top
Usage: Interactive real-time process monitor
top
Description: Press q to quit, 1 to show CPUs, M to sort by memory.
btop
Usage: Advanced system monitor (better than htop/top)
btop
Description: Modern, resource-efficient system monitor with beautiful UI. Install with: apt install btop or brew install btop
ps aux | grep process
Usage: Find processes by name with memory/CPU usage
ps aux | grep "node"
free -h
Usage: Show memory usage (human-readable)
free -h
df -h
Usage: Disk space usage by filesystem
df -h
du -sh /path/
Usage: Directory size
du -sh /var/log
du -sh *
Usage: Size of each item in directory
du -sh * | sort -h
watch -n 2 command
Usage: Run command repeatedly every N seconds
watch -n 2 'docker ps'
Description: Perfect for monitoring. Press Ctrl+C to stop.
time command
Usage: Measure command execution time
time npm run build

Network & Connectivity Tools

curl -I URL
Usage: Check HTTP response headers (status code)
curl -I https://api.example.com
curl -v URL
Usage: Verbose curl (show full request/response)
curl -v https://api.example.com
curl -X POST -d @file.json URL
Usage: Send POST request with JSON payload
curl -X POST -H "Content-Type: application/json" -d '{"key":"value"}' https://api.example.com
wget URL
Usage: Download file from URL
wget https://example.com/file.zip
netstat -tuln
Usage: List listening ports and services
netstat -tuln | grep LISTEN
Description: t=TCP, u=UDP, l=listening, n=numeric.
ss -tuln
Usage: Modern alternative to netstat
ss -tuln | grep :8080
lsof -i :PORT
Usage: Find process using specific port
lsof -i :3000
Description: Great for finding what's running on a port.
ping -c 4 domain.com
Usage: Test connectivity to host
ping -c 4 google.com
dig domain.com
Usage: DNS lookup
dig api.github.com
traceroute domain.com
Usage: Trace network path to host
traceroute google.com

Environment Variables & PATH Management

echo $VARIABLE
Usage: Print environment variable value
echo $PATH
export VARIABLE="value"
Usage: Set environment variable
export NODE_ENV="production"
env
Usage: Show all environment variables
env | grep NODE
export PATH="$PATH:/new/path"
Usage: Add to PATH
export PATH="$PATH:$HOME/bin"
which command
Usage: Find command location in PATH
which python
source ~/.bashrc or ~/.zshrc
Usage: Reload shell configuration
source ~/.zshrc
Description: Apply changes to .bashrc/.zshrc without restarting shell.

Archive & Compression

tar -czf archive.tar.gz folder/
Usage: Create compressed tar archive
tar -czf backup.tar.gz project/
Description: c=create, z=gzip compress, f=file.
tar -xzf archive.tar.gz
Usage: Extract tar.gz archive
tar -xzf backup.tar.gz
Description: x=extract, z=gunzip, f=file.
zip -r archive.zip folder/
Usage: Create zip archive
zip -r project.zip src/
unzip archive.zip
Usage: Extract zip archive
unzip project.zip

Git Advanced Workflows

git log --oneline --graph --all
Usage: Visual git history
git log --oneline --graph --all
git diff HEAD~1 HEAD
Usage: Compare last 2 commits
git diff HEAD~1 HEAD
git stash
Usage: Save uncommitted changes temporarily
git stash
git stash pop
Usage: Restore stashed changes
git stash pop
git cherry-pick COMMIT
Usage: Apply specific commit to current branch
git cherry-pick abc123def
git rebase -i HEAD~3
Usage: Interactive rebase (edit last 3 commits)
git rebase -i HEAD~3
⚠️ Don't rebase public commits!
git push --force-with-lease
Usage: Force push safely (rebase-aware)
git push --force-with-lease
Description: Safer than --force, checks for remote changes.

Useful Shell Functions & One-Liners

function_name() { commands; }
Usage: Define shell function
# Find which process is using a port port_info() { lsof -i :$1; } port_info 3000
find large files
Usage: One-liner to find largest files
find . -type f -exec du -h {} + | sort -rh | head -10
batch rename files
Usage: Rename files matching pattern
for file in *.txt; do mv "$file" "${file%.txt}.log"; done
create multiple directories
Usage: Create nested directory structure
mkdir -p src/{components,pages,utils}/{hooks,styles,types}
quick backup
Usage: Backup file with timestamp
cp config.json config.json.$(date +%Y%m%d_%H%M%S)
parallel downloads
Usage: Download multiple files in parallel
cat urls.txt | xargs -P 5 -I {} wget {}
Description: -P 5 = 5 parallel jobs.
Pro Tips:
• Use !!; to repeat last command with sudo
• Use !$ to reference last argument
• Use Ctrl+R to search command history
• Combine commands with pipes for powerful workflows
• Always test destructive commands (rm, sed -i) on copies first
