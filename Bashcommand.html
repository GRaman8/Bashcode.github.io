Section 1: Bash Commands Guide

Bash (Bourne Again Shell) is the default shell in most Linux systems and macOS. It's used for command-line operations, scripting, and system administration. Here are the essential commands for navigating and managing files.

Basic Tips:
• Use Tab for command/filename autocomplete
• Use history or Ctrl+R to search previous commands
• Use man command to view manual pages
• Use | (pipe) to connect commands: command1 | command2

File & Directory Navigation

cd
Usage: Change directory
cd /path/to/directory
Other Ways: cd .. (parent directory), cd ~ (home), cd - (previous)
ls
Usage: List directory contents
ls -la /path/to/directory
Other Ways: ls -lh (human-readable), ls -R (recursive)
Description: -l: detailed format, -a: show hidden files, -h: human-readable sizes.
pwd
Usage: Print current working directory
pwd
Description: Shows the full path of the current directory.
mkdir
Usage: Create a new directory
mkdir my_folder
Other Ways: mkdir -p path/to/nested/folder (create parent directories)
rmdir
Usage: Remove an empty directory
rmdir my_folder
Description: Only works if the directory is completely empty.

File Operations

touch
Usage: Create an empty file
touch file.txt
rm
Usage: Remove files or directories
rm file.txt
Other Ways: rm -r folder (recursive), rm -f file (force)
⚠️ Caution: rm permanently deletes files. Use with care! Consider using mv to trash instead.
cp
Usage: Copy a file or directory
cp source.txt destination.txt
Other Ways: cp -r folder1 folder2 (recursive copy)
mv
Usage: Move or rename a file or directory
mv old_name.txt new_name.txt
Description: Also used to move files: mv file.txt /path/to/destination/

File Viewing & Display

cat
Usage: Display file contents
cat file.txt
Description: Displays entire file at once. Use with large files cautiously.
less
Usage: View file page by page
less file.txt
Description: Press q to quit, Space to page down, b for page up, /pattern to search.
more
Usage: Display file content page by page (older than less)
more file.txt
head
Usage: Display the first lines of a file
head -20 file.txt
Description: Default is 10 lines. Use -n to specify number: head -n 5 file.txt
tail
Usage: Display the last lines of a file
tail -20 file.txt
Other Ways: tail -f file.txt (follow/watch for changes)

Text Search & Processing

grep
Usage: Search for patterns in files
grep "pattern" file.txt
Other Ways: grep -i "pattern" file.txt (case-insensitive), grep -r "pattern" /path/ (recursive)
sed
Usage: Stream editor — find and replace text
sed 's/old/new/g' file.txt
Description: s = substitute, g = global (all occurrences). Use -i to edit in place.
awk
Usage: Pattern-matching for data extraction and manipulation
awk '{print $1, $3}' file.txt
Description: Powerful for processing columnar data. $1 = first column, $2 = second, etc.
wc
Usage: Count lines, words, and characters
wc -l file.txt
Other Ways: wc -w file.txt (words), wc -c file.txt (bytes)

File Permissions & Ownership

chmod
Usage: Change file permissions
chmod 755 script.sh
Description: 755 = rwxr-xr-x (owner: read/write/execute, others: read/execute). chmod +x adds execute permission.
chown
Usage: Change file owner and group
chown user:group file.txt

Output & Text Utilities

echo
Usage: Print text to the terminal
echo "Hello, World!"
printf
Usage: Formatted print (more control than echo)
printf "Name: %s, Age: %d\n" "$name" "$age"
