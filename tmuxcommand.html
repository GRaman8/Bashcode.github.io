Section 3: Tmux Commands Guide

Tmux (Terminal Multiplexer) is a powerful tool for managing multiple terminal sessions and panes within a single window. Perfect for remote servers, long-running processes, and complex workflows.

What is Tmux?
Tmux lets you:
• Create multiple sessions and switch between them
• Split windows into panes
• Detach and reattach sessions
• Keep sessions running even if disconnected (SSH)
• Default prefix key: Ctrl+B (press once, then press command key)

Session Management

tmux new -s session_name
Usage: Create a new session
tmux new -s development
Description: Creates a new named session. You're automatically attached to it.
tmux new -s session_name -d
Usage: Create a new session in the background (detached)
tmux new -s server -d "python app.py"
Description: -d flag creates session without attaching. Useful for starting processes.
tmux ls
Usage: List all active sessions
tmux ls
tmux attach -t session_name
Usage: Attach to an existing session
tmux attach -t development
Other Ways: tmux a -t session_name (shorthand)
Ctrl+B then D
Usage: Detach from current session (keep it running)
Description: Session continues running in background. Reconnect anytime with tmux attach -t session_name
tmux kill-session -t session_name
Usage: Kill a session
tmux kill-session -t old-session
tmux kill-server
Usage: Kill all sessions and tmux server
Description: Use with caution! Terminates everything.
tmux rename-session -t old_name new_name
Usage: Rename a session
tmux rename-session -t dev development

Window Management

Ctrl+B then C
Usage: Create a new window in the current session
Description: Each window is like a separate terminal tab.
Ctrl+B then N
Usage: Go to next window
Ctrl+B then P
Usage: Go to previous window
Ctrl+B then # (0-9)
Usage: Jump to a specific window by number
Ctrl+B then 0 (go to window 0)
Ctrl+B then W
Usage: List and choose windows
Description: Shows interactive window selector.
Ctrl+B then X
Usage: Close/kill current window
Ctrl+B then ,
Usage: Rename current window

Pane Management (Splits)

Ctrl+B then %
Usage: Split window vertically (left/right)
Description: Creates two side-by-side panes.
Ctrl+B then " (double quote)
Usage: Split window horizontally (top/bottom)
Description: Creates two stacked panes.
Ctrl+B then Arrow Keys
Usage: Move focus between panes
Ctrl+B then ← (move to left pane)
Ctrl+B then O
Usage: Move to next pane (cycle through)
Ctrl+B then Z
Usage: Zoom/maximize current pane (toggle)
Description: Toggle pane to full size and back.
Ctrl+B then X
Usage: Kill current pane
Ctrl+B then Space
Usage: Cycle through pane layouts
Description: Automatically arranges panes in different layouts.
Ctrl+B then Ctrl+Arrow
Usage: Resize pane
Ctrl+B then Ctrl+← (make left pane narrower)

Copy & Paste

Ctrl+B then [
Usage: Enter copy mode
Description: Allows scrolling and selecting text. Use arrow keys or vim keys to navigate.
Space (in copy mode)
Usage: Start selecting text
Enter (in copy mode)
Usage: Copy selected text
Ctrl+B then ]
Usage: Paste copied text

Useful Settings & Configuration

tmux show-options -g
Usage: Show global configuration options
~/.tmux.conf
Usage: Tmux configuration file
Description: Create this file to customize tmux. Example settings:
set -g mouse on (enable mouse)
set -g base-index 1 (start window numbering at 1)
bind r source-file ~/.tmux.conf (reload config)
Ctrl+B then :
Usage: Enter tmux command prompt
Description: Type commands like send-keys -t session "command"

Common Workflows & Use-Cases

Remote development with persistent session
# On remote server: tmux new -s dev # Do work, detach with Ctrl+B then D # Later, reconnect: tmux attach -t dev
Description: Session survives SSH disconnects. Perfect for remote development!
Run multiple services in one tmux session
tmux new -s services tmux send-keys -t services "python backend.py" Enter tmux new-window -t services tmux send-keys -t services "npm start" Enter
Quick pair programming setup
tmux new -s pair -d # Create session tmux send-keys -t pair "code ." Enter # Start editor
Pro Tips:
• Use Ctrl+B ? to list all keybindings
• Enable mouse support in ~/.tmux.conf: set -g mouse on
• Use plugins like Tmux Plugin Manager (tpm) for extended functionality
• Combine tmux with screen or detach functionality for robust workflows
