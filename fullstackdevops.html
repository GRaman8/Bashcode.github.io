Common Deployment Workflows

Full Stack App Deployment

Complete Node.js deployment
# 1. Clone repo git clone https://github.com/user/project.git cd project # 2. Install dependencies npm install # 3. Build (if needed) npm run build # 4. Start with PM2 (process manager) npm install -g pm2 pm2 start npm --name "app" -- start pm2 save pm2 startup # 5. Setup Nginx reverse proxy sudo systemctl restart nginx

Docker Deployment

Docker app deployment
# 1. Build image docker build -t myapp:latest . # 2. Run container with volume mount docker run -d \ --name app \ -p 3000:3000 \ -e NODE_ENV=production \ -v /app/data:/data \ myapp:latest # 3. Check logs docker logs -f app

Database Backup Strategy

Daily backup cron job
# Add to crontab (crontab -e) 0 2 * * * pg_dump -U postgres mydb > /backups/mydb-$(date +\%Y\%m\%d).sql # This backs up every day at 2:00 AM
Pro Tips for Full Stack Developers:
• Use direnv to manage per-project environment variables
• Always use docker-compose.yml for local development (matches production)
• Keep database backups in S3 with versioning enabled
• Use Terraform for infrastructure, Docker for applications
• Test all deployments in staging before production
• Monitor logs with tail -f during deployments
• Use pm2 ecosystem.config.js for multiple services
